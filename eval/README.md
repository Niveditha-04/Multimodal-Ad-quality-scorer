# Phase 8: LLM explanation evaluation

This phase evaluates the RAG plus LLM explanation layer, in
`rag/explain.py`, against an independently labeled golden set. RAG stands
for retrieval-augmented generation. It means the system looks up relevant
policy text before asking the LLM to write an explanation, rather than
relying on the LLM's own memory of the rules.

We score each explanation on three axes: groundedness (is the image
described accurately), rule accuracy (does it cite the policy rule that
genuinely applies), and hallucination (does it assert anything specific
and unverifiable as fact).

## Reproducing this

```bash
python -m eval.build_golden_set        # selects 32 flagged test-set ads, writes eval/golden_set.json
python -m eval.generate_explanations   # runs each through rag.explain.generate_explanation(), writes eval/generated_explanations.json
python -m eval.compute_results         # aggregates eval/scores.py against the golden set, writes eval/results.json
```

The scoring itself, in `eval/scores.py`, is a manually authored file. It is
not regenerated by a script. See "How scoring was done" below for why.

## Build order, and why it matters

1. **The rubric was written and locked first**, in `eval/rubric.md`,
   before any explanation was generated or seen. It has three axes, each
   scored on a 0, 1, 2 scale. It includes an explicit special case for
   genuinely compliant ads: any asserted rule violation on a truly
   `approved` ad scores rule accuracy 0 automatically. This rubric was not
   edited after scoring started.
2. **The golden set was built second.** It has 32 ads drawn from the
   96-ad test set. Every one of them is an ad the classifier actually
   flagged, since only flagged ads get an explanation. It includes all 4
   of this test set's genuine misclassification cases, not a
   cherry-picked subset, plus a confidence-spread sample of true positives
   across the three violation categories. That sample has 11
   `policy_violation` ads, 9 `misleading` ads, and 9 `low_quality` ads.
3. **Ground truth was sourced independently.** Species and breed come
   from `data/dataset.csv`'s `source_species` and `source_breed` columns.
   These columns were recorded from the Oxford Pet filename convention at
   dataset-construction time, before any model or LLM ever touched this
   data. This means the ground truth is not vulnerable to the failure
   mode where the same reasoning that writes an explanation also grades
   it. Which policy rule genuinely applies was determined by matching
   each ad's actual text against the known violation templates in
   `data/build_dataset.py`. We additionally confirmed 8 of the 32 ads by
   directly viewing the image file, not just trusting the metadata. This
   set of 8 covers all 4 misclassification cases, one true positive from
   each category, and one example of each `low_quality` subtype.
4. **A human spot-checked the ground truth before scoring began.** The
   golden set's ground truth was reviewed and confirmed correct by a
   human before any explanation was generated or scored. The "core
   finding" note below was added at this checkpoint.
5. **Explanations were generated** using the real
   `rag.explain.generate_explanation()` function. This is the same code
   that `/score` and the MCP tool call, not a separate copy of it. Each
   call used the ad's already-recorded `model_predicted_label`, not a
   fresh classification. This isolates what is being evaluated to the
   explanation layer, holding the classifier's decision fixed.
6. **Explanations were scored against the locked rubric**, in
   `eval/scores.py`.

## How scoring was done

Scoring was done by direct example-by-example review against the rubric.
It was not delegated to another LLM call. Using a model to grade another
model's output here would risk the same correlated-error problem this
phase exists to guard against. If grading shares the same reasoning
tendencies as generation, systematic errors could look like agreement
rather than accuracy. The file `eval/scores.py` is a manually authored
data file with a one-line justification note for every example that
scores below 2 on any axis. The file `eval/compute_results.py` aggregates
these scores programmatically. It also cross-checks that every golden-set
ad has exactly one score, so nothing is silently omitted.

## Results

Full numbers are in `eval/results.json`. Here are the per-axis results.

| Axis | Mean (0 to 2) | Failure rate (score of 0) |
|---|---|---|
| Groundedness | 1.656 | 6.2% (2 of 32) |
| Rule accuracy | 1.656 | 9.4% (3 of 32) |
| Hallucination | 1.438 | 25.0% (8 of 32) |

**Headline finding: 8 of 32 generated explanations, 25.0%, contain a major
hallucination.** A major hallucination is a specific, checkable claim,
central to the stated reasoning, that is fabricated. We report this
plainly because it is the actual finding, not something to minimize. This
evaluation exists specifically to surface this number. A non-trivial
hallucination rate was expected going in, based on the
misclassification-explanation limitation already documented in the v1
README.

32 examples is a small sample. The 95% confidence interval on this rate is
13.3% to 42.1%, computed the same way as the other confidence intervals
in this project (see below). Because the sample is small, 25.0% should be
read as a point estimate, not as a precise, decimal-stable rate. The
confidence interval is the number to carry forward, not the headline
percentage alone.

### The hallucination pattern is not confined to misclassified ads

We broke this down by whether the classifier's prediction was itself
correct. Both subgroups below are small, 4 and 28 examples, so these
splits should be read as directional, not as independently precise rates.

| Group | Count | Hallucination mean | Hallucination failure rate |
|---|---|---|---|
| Misclassified ads (prediction does not match ground truth) | 4 | 0.25 | 75% (3 of 4) |
| True-positive ads (prediction matches ground truth) | 28 | 1.607 | 17.9% (5 of 28) |

The 75% rate on misclassified ads confirms the v1 finding, now with more
evidence than the original single example. When the classifier is wrong,
the explanation does not hedge. It fabricates a specific justification for
the wrong verdict. All 3 of the misclassified-and-hallucinated cases, ad
IDs 6, 97, and 105, are genuinely compliant ads that were wrongly flagged
as `misleading`. All 3 independently invented the same fabricated
requirement: that the literal product must be visibly depicted in the
photo for the ad to be compliant.

**We traced this to a specific, identifiable cause, not to generic model
unreliability.** See `eval/root_cause_analysis.md` for the full
investigation. The `mismatched_creative` rule's own text, in
`db/policy_categories.py`, reads: "the product or animal shown in the
image must match... mismatches between the pictured animal/product...".
This wording pairs "product" with "animal" as things that should both
appear in the image. We re-ran the actual retrieval call for every
hallucinating example and confirmed this exact rule text was present in 7
of the 8 major-hallucination prompts. Four came from the `misleading`
cases through guaranteed retrieval. The other four, newly confirmed here
and not previously known, are `policy_violation` cases where this rule
surfaced through pure semantic search, not a guarantee. The one exception,
ad 412, in the `low_quality` category, retrieved no rule mentioning image
content at all. We report it as a separate, less-understood failure mode
rather than folding it into the same explanation. This makes the finding
sharper than "the LLM hallucinates." 7 of 8 major hallucinations
mis-generalize from one identifiable, ambiguous sentence in this
project's own retrieval corpus. That is a fixable defect, not a vague
reliability concern.

See `eval/golden_set_findings.md` for the cross-check against the full
Phase 2 confusion matrix. That cross-check confirms this is a systematic
pattern, not 4 independent flukes: all 4 of this test set's
misclassifications land as false `misleading` predictions, and none land
as false `policy_violation` or `low_quality` predictions.

The more surprising finding is the second row of the table above. Even
when the classifier's prediction is correct, a fabricated violation still
shows up in 5 of 28 true-positive explanations, ad IDs 144, 157, 185, 211,
and 412. In each case, it is tacked on as an additional, incorrectly
asserted violation alongside an otherwise correct one. Four of these,
144, 157, 185, and 211, are the same traced `mismatched_creative`
product-visibility fabrication described above. Each is framed as a
co-equal independent violation, using language like "flagged... on two
counts," not as a hedge. One of them, ad 185, compounds into a second
fabrication. It misidentifies a genuine American Pit Bull Terrier, which
we visually confirmed, as "not identifiable" as that breed, in order to
manufacture a species-mismatch claim that does not exist. The fifth case,
ad 412, does not trace to this cause. Its retrieved rules contained no
image-content language, so it is reported as a separate, unexplained
fabrication rather than grouped with the other four for a
cleaner-looking story.

### Rule accuracy: mostly clean, with one genuine ambiguity worth naming

3 of the 32 examples that scored 0 on rule accuracy are exactly the 3
genuinely compliant misclassified ads. These score 0 automatically under
the rubric's special case, since any asserted rule is wrong by definition
when no rule genuinely applies.

Ad 146 and ad 157 both score 1 rather than 0 or 2, for a real,
pre-acknowledged ambiguity. Their ad text was constructed from a template
that genuinely mixes two violation patterns. For ad 146, that is
health-and-guarantee language plus superlative language. For ad 157, that
is fear-based language plus absolute-efficacy language. So the model
citing the "other" genuine pattern is not fabrication. It is just not the
primary category this golden set pre-committed to. We flag this rather
than silently resolving it in either direction.

### Groundedness: the strongest axis, with one real image-description error

23 of 32 examples score a full 2 on groundedness. The only 0-scores are
ad 144, which misidentifies a wheaten terrier as a "Goldendoodle" (a real,
specific, wrong visual claim, though not central to why the ad was
correctly flagged), and ad 185, the breed misidentification described
above. 7 of 32 examples score 1, solely because the explanation makes no
image claim at all. Several `policy_violation` cases and
`low_quality`-text-subtype cases correctly do not need to describe the
image to justify a pure-text violation. Under the rubric, this scores 1,
not 2, since there is nothing to verify. It is not an accuracy failure
either.

## Limitations of this evaluation itself

32 examples is a small sample. Per-axis failure rates carry real sampling
uncertainty. The Wilson 95% confidence interval on the headline 8-of-32,
25.0%, hallucination rate is 13.3% to 42.1%. This is computed the same way
as the confidence intervals in `model/results/confidence_intervals.json`.
The interval is wide, but it sits entirely above the range you would
expect for a rare edge case. Even at the low end, this is not a
negligible rate.

Scoring was done by one reviewer, this session, not by a second
independent scorer. Inter-rater agreement was not measured. The
per-example notes in `eval/scores.py` exist specifically so a second
reviewer could check the reasoning behind each score, not just the number
itself.

The golden set draws only from this project's synthetic dataset, which is
pet-product ads. The hallucination pattern found here, a specific
fabricated policy requirement invented to justify a verdict, may or may
not generalize to other domains.
