# Phase 8: LLM explanation evaluation

Evaluates the RAG+LLM explanation layer (`rag/explain.py`) against an
independently-labeled golden set, on three axes: groundedness (is the
image described accurately), rule accuracy (does it cite the policy rule
that genuinely applies), and hallucination (does it assert anything
specific and unverifiable as fact).

## Reproducing this

```bash
python -m eval.build_golden_set        # selects 32 flagged test-set ads, writes eval/golden_set.json
python -m eval.generate_explanations   # runs each through rag.explain.generate_explanation() -> eval/generated_explanations.json
# scoring (eval/scores.py) is a manually-authored file, not regenerated by a script --
# see "How scoring was done" below for why
python -m eval.compute_results         # aggregates eval/scores.py against the golden set -> eval/results.json
```

## Build order (and why)

1. **`eval/rubric.md` written and locked first**, before any explanation was
   generated or seen. Three axes, 0/1/2 scale each, with an explicit special
   case for genuinely-compliant ads (any asserted rule violation on a truly
   `approved` ad scores rule_accuracy=0 automatically, regardless of how
   fluently argued). Not edited after scoring started.
2. **`eval/golden_set.json` built second**: 32 ads from the 96-ad test set,
   every one of them an ad the classifier actually flagged (since only
   flagged ads get an explanation). Includes **all 4** of this test set's
   genuine misclassification cases (ad_ids 6, 97, 105, 146), not a
   cherry-picked subset, plus a confidence-spread sample of true positives
   across the three violation categories (11 `policy_violation`, 9
   `misleading`, 9 `low_quality`).
3. **Ground truth independently sourced**: species/breed comes from
   `data/dataset.csv`'s `source_species`/`source_breed` -- recorded from the
   Oxford Pet filename convention at dataset-construction time, before any
   model or LLM ever touched this data, so it isn't vulnerable to the
   failure mode where the same reasoning that writes an explanation also
   grades it. Which policy rule genuinely applies was determined by matching
   each ad's actual text against the known violation templates in
   `data/build_dataset.py`. 8 of the 32 (all 4 misclassification cases, one
   true positive from each category, one of each `low_quality` subtype)
   were additionally confirmed by directly viewing the image file, not just
   trusting the metadata.
4. **Human spot-check before scoring**: the golden set's ground truth was
   reviewed and confirmed correct by a human before any explanation was
   generated or scored (see the "core finding" note below, added at this
   checkpoint).
5. **Explanations generated** via the real `rag.explain.generate_explanation()`
   function -- the same code `/score` and the MCP tool call -- using each
   ad's already-recorded `model_predicted_label`, not a fresh classification.
   This isolates what's being evaluated to the explanation layer, holding
   the classifier's decision fixed.
6. **Scored against the locked rubric** in `eval/scores.py`.

## How scoring was done

Scored by direct example-by-example review against the rubric, not
delegated to another LLM call. Using a model to grade another model's
output here would risk exactly the correlated-error problem this phase
exists to guard against -- if grading shares the same reasoning tendencies
as generation, systematic errors could look like agreement rather than
accuracy. `eval/scores.py` is a manually-authored data file with a
one-line justification note per example scoring below 2 on any axis;
`eval/compute_results.py` aggregates it programmatically (and cross-checks
every golden-set ad has exactly one score, no silent omissions).

## Results

Full numbers: `eval/results.json`. Per-axis:

| Axis | Mean (0-2) | Failure rate (score=0) |
|---|---|---|
| Groundedness | 1.656 | 6.2% (2/32) |
| Rule accuracy | 1.656 | 9.4% (3/32) |
| **Hallucination** | 1.438 | **25.0% (8/32)** |

**Headline finding: 8 of 32 (25.0%) generated explanations contain a major
hallucination** -- a specific, checkable claim, central to the stated
reasoning, that is fabricated. Reported plainly because it is the actual
finding, not minimized: this evaluation exists specifically to surface this
number, and a non-trivial hallucination rate was expected going in, per the
misclassification-explanation limitation already documented in the v1
README. 32 examples is a small sample -- the 95% CI on this rate is
[13.3%, 42.1%] (see below) -- so **25.0% is a point estimate from a small
golden set, not a precise, decimal-stable rate**; the CI is the number to
carry forward, not the headline percentage alone.

### The hallucination pattern isn't confined to misclassified ads

Broken out by whether the classifier's prediction was itself correct (both
subgroups are small -- 4 and 28 -- so treat these splits as directional,
not as independently precise rates):

| | n | Hallucination mean | Hallucination failure rate |
|---|---|---|---|
| Misclassified ads (pred != ground truth) | 4 | 0.25 | **75% (3/4)** |
| True-positive ads (pred == ground truth) | 28 | 1.607 | **17.9% (5/28)** |

The 75% rate on misclassified ads confirms the v1 finding with more
evidence than the original single example: when the classifier is wrong,
the explanation doesn't hedge -- it fabricates a specific justification for
the wrong verdict. All 3 of the misclassified-and-hallucinated cases (ad
6, 97, 105 -- the genuinely-compliant ads wrongly flagged `misleading`)
independently invented the **same** fabricated requirement: that the
literal product must be visibly depicted in the photo for the ad to be
compliant.

**Traced this to a specific, identifiable cause, not generic model
unreliability** -- see `eval/root_cause_analysis.md`. The `mismatched_creative`
rule's own text (`db/policy_categories.py`) reads "**the product or animal**
shown in the image must match... mismatches between the **pictured
animal/product**..." -- pairing "product" with "animal" as things that
should both appear in the image. Re-running the actual retrieval call for
every hallucinating example confirmed this exact rule text was present in
7 of the 8 major-hallucination prompts (the 4 `misleading` cases via
guaranteed retrieval, plus -- newly confirmed, not previously known --
4 `policy_violation` cases where it surfaced via pure semantic search, not
a guarantee). The one exception (ad 412, `low_quality`) retrieved no rule
mentioning image content at all and is reported as a separate, less-understood
failure mode rather than folded into the same explanation. This makes the
finding sharper than "the LLM hallucinates": 7 of 8 major hallucinations
mis-generalize from one identifiable, ambiguous sentence in this project's
own retrieval corpus -- a fixable defect, not a vague reliability concern.
See `eval/golden_set_findings.md` for the cross-check against the full Phase 2
confusion matrix confirming this is a systematic pattern (all 4 of this
test set's misclassifications land as false `misleading` predictions, none
as false `policy_violation` or `low_quality`), not 4 independent flukes.

The more surprising finding is the second row: **even when the classifier's
prediction is correct**, a fabricated violation still shows up in 5 of 28
true-positive explanations (144, 157, 185, 211, 412) -- tacked on as an
additional, incorrectly-asserted violation alongside an otherwise correct
one. Four of these (144, 157, 185, 211) are the *same* traced
`mismatched_creative` product-visibility fabrication described above, each
framed as a co-equal independent violation ("flagged... on two counts"),
not a hedge -- and one (185) compounds into a second fabrication,
misidentifying a genuine American Pit Bull Terrier (visually confirmed) as
"not identifiable" as that breed to manufacture a species-mismatch claim
that doesn't exist. The fifth (412) is the one case that does **not** trace
to this cause -- its retrieved rules contained no image-content language,
so it's reported as a separate, unexplained fabrication rather than
grouped with the other four for a cleaner-looking (but less accurate) story.

### Rule accuracy: mostly clean, with one genuine ambiguity worth naming

3 of 32 rule_accuracy=0 are exactly the 3 genuinely-compliant misclassified
ads (auto-0 per the rubric's special case -- any asserted rule is wrong by
definition when no rule genuinely applies). Ad 146 and ad 157 both score 1
rather than 0 or 2 for a real, pre-acknowledged ambiguity: their ad text
was constructed from a template that genuinely mixes two violation
patterns (health/guarantee language AND superlative language for 146;
fear-based language AND absolute-efficacy language for 157), so the model
citing the "other" genuine pattern isn't fabrication, just not the primary
category this golden set pre-committed to. This is flagged rather than
silently resolved either direction.

### Groundedness: the strongest axis, with one real image-description error

23 of 32 score a full 2; the only 0-scores are ad 144 (misidentifies a
wheaten terrier as a "Goldendoodle" -- a real, specific, wrong visual
claim, though not central to why the ad was correctly flagged) and ad 185
(the breed-misidentification described above). 7 of 32 score 1 solely
because the explanation makes no image claim at all (several
`policy_violation` and `low_quality`-text-subtype cases correctly don't
need to describe the image to justify a pure-text violation) -- per the
rubric this is scored 1, not 2, since there's nothing to verify, but it
isn't an accuracy failure either.

## Limitations of this evaluation itself

- 32 examples is small; per-axis failure rates carry real sampling
  uncertainty -- the Wilson 95% CI on the headline 8/32=25.0% hallucination
  rate is [13.3%, 42.1%], computed the same way as the confidence intervals
  in `model/results/confidence_intervals.json`. Wide, but the interval sits
  entirely above the "rare edge case" range -- even at the low end this is
  not a negligible rate.
- Scoring was done by one reviewer (this session), not a second
  independent scorer -- inter-rater agreement wasn't measured. The
  per-example notes in `eval/scores.py` exist specifically so a second
  reviewer could check the reasoning, not just the number.
- The golden set draws only from this project's synthetic dataset (pet
  product ads); the hallucination pattern found here (a specific fabricated
  policy requirement invented to justify a verdict) may or may not
  generalize to other domains.
